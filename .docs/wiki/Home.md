# formvfx

Motion graphics and visual effects in the form family, beside formvis (images) and formcut (video). Compositions, layers, keyframes and the Graph Editor, 300 effects and WebAssembly plug-ins, Essential Graphics templates, text and shape animation, masks, Roto Brush, paint, puppet pins, 3D cameras and lights, tracking with a learned face model, expressions, scripts and ScriptUI panels and a Render Queue, on macOS, Windows, Linux and in the browser.

Every action in formvfx is a command with an id, so people and agents use the same tools: Claude Code, Codex and Cursor drive formvfx from its embedded terminal through MCP, with a skill that teaches them the workflow.
