# Agents

formvfx exposes all of its commands to agents. Changes they make appear in the window live and are ordinary undo steps.

## In the Terminal panel

The Terminal panel opens a shell in formvfx's agent workspace (`~/Formvfx/agent-workspace`). The Claude Code, Codex and Cursor buttons start those clients there; each finds the `formvfx` MCP server and the `formvfx-harness` skill in the folder. Agents started here are trusted and never see a permission prompt.

## From this repository or anywhere

- In the repository, `.mcp.json` (Claude Code), `.codex/config.toml` (Codex) and `.cursor/mcp.json` (Cursor) run `./formvfx mcp`.
- `./formvfx agents install` (or Install in the Agents panel) adds the MCP server and the skill to your Claude Code, Codex and Cursor setup, backing up any file it changes.
- The first change from an outside agent asks once in the formvfx window: Allow, Allow Always or Don't Allow. `FORMVFX_AGENTS=allow` or `deny` on the engine changes the policy.

## The tools

`status`, `list_commands`, `describe_command`, `execute`, `batch`, `get_comp`, `get_layer`, `get_property`, `set_property`, `set_keyframes`, `apply_effect`, `list_effects`, `text_preset`, `shapes_from_svg`, `planar_track`, `object_matte`, `render_frame`, `contact_sheet`, `render`, `dynamic_link`, `project`, `import_files`, `history`, `ui`, `wait`, `guide`. The full reference is `.claude/skills/formvfx-harness/references/tools.md`.

## Command line

```bash
./formvfx state
./formvfx commands layer.new
./formvfx describe layer.newText
./formvfx exec comp.new '{"name": "Promo", "width": 1920, "height": 1080, "duration": 6}'
./formvfx batch '[{"command": "layer.newText", "params": {"text": "Hello"}}]'
./formvfx frame out.png --time 1.5
```

## The skill

`.claude/skills/formvfx-harness` (mirrored to `.agents/skills`) teaches agents the model, the build loop and each area of the application, with recipes that were run against the engine. Its references for commands, effects, property paths and tools are generated by `./formvfx agents sync` from the engine itself.
