# Manual

The formvfx manual lives in the repository as [`docs/MANUAL.md`](https://github.com/nodemode-ai/formvfx/blob/main/docs/MANUAL.md) and opens inside formvfx from Help > formvfx Manual. It walks through the application area by area with the menu path of every tool: the window, panels and workspaces, projects and footage, compositions and layers, the Flowchart as a node editor, animation, text, shapes and masks, rotoscoping, paint and puppet, effects and plug-ins, 3D, tracking, expressions and scripts, preview, rendering and export, colour, Dynamic Link, agents and the tutorials.

Every menu item is also a command; [Agents](Agents) shows how Claude Code, Codex and Cursor run the same commands.
