# Parity

formvfx is measured against After Effects row by row in [`docs/PARITY.md`](https://github.com/nodemode-ai/formvfx/blob/main/docs/PARITY.md): 72 capability rows across project and footage, compositions, layers, animation, text, shapes, masks and rotoscoping, effects, 3D, tracking, expressions and scripting, preview, rendering, colour, audio and the interface. Each row is traced through the engine command, the interface that exposes it and the render or export path, and marked Full, Partial or None, with whether it was run end to end in that build.

The page also lists where formvfx trails, in order of priority, and where it leads.
