Generated from the formvfx engine by `./formvfx agents sync`; do not edit by hand.

307 effects in 21 categories. Apply with `apply_effect {layer, effect, params}` (the id or the name) or `execute effect.apply {effect, layers}`. Each parameter is listed as `id` = default (control). After applying, the parameter's property path is `effects/#N/[id]` where N is the effect's position on the layer (1 = top); `get_layer` shows the exact paths. GPU marks effects that render on the GPU when it is available; every effect also renders on the CPU.
